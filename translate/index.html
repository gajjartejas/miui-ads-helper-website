MIUI ADS HELPER / TRANSLATE

Help translate the app

Make the guides easier to follow in your language.

Improve an existing translation

Translations live in the app’s locale JSON files. Find the relevant language, keep the translation keys unchanged, and update the wording. Preserve placeholders, numbered steps, and formatting markers such as double asterisks around setting names.

Open translation files ↗

Suggest a new language

Open a GitHub issue with the language name and what you would like to contribute. Please check the current repository structure and contribution guidance before submitting changes.

Report unclear instructions

Include the guide name and language, plus the wording you suggest. Do not include personal data or device identifiers in a public issue.
